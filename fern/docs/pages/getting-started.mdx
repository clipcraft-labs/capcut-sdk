# Clipcraft and the CapCut API SDK

Clipcraft is a local SDK and CLI toolchain for discovering CapCut catalogue
resources and compiling portable JSON projects into CapCut Desktop drafts. It
is not a hosted rendering service: catalogue requests, asset storage, project
compilation, and Desktop registration run on your computer.

```bash
capcut effects search "blur"
clipcraft catalog effects search "blur"
```

Use `capcut` when you want direct SDK and observed API access. Use `clipcraft`
when you want the complete reproducible project workflow:

```text
live catalogue search
  -> normalized resource
  -> clipcraft.lock
  -> project.json
  -> self-contained render package
  -> optional Desktop registration or configured headless runner
```

Start with [Install](./installation.mdx), then follow
[Build your first project](./clipcraft-workflow.mdx). The project compiler is
currently verified for CapCut Desktop 9.1.0 on macOS. The public packages do
not include CapCut binaries, downloaded resources, or the native headless
runner.

Clipcraft is unofficial and is not affiliated with or endorsed by CapCut or
ByteDance.

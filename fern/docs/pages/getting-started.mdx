# CapCut API SDK

The CapCut API SDK provides a Python client and CLI for the observed CapCut
Desktop API surface.

```bash
python -m pip install git+https://github.com/clipcraft-labs/capcut-sdk.git
capcut effects search "blur"
```

The first command creates a local default profile. Catalog endpoints can be
queried immediately; login-required endpoints may require a real profile.

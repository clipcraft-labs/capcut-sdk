# CLI reference

The `capcut` command uses the default local profile automatically. The first
catalog command creates that profile if it does not exist.

## Profile management

```bash
capcut auth profile list
capcut auth profile show [name]
capcut auth profile set [name] \
  [--device-id VALUE] \
  [--iid VALUE] \
  [--region VALUE] \
  [--language VALUE] \
  [--mode offline|live|replay]
```

Examples:

```bash
capcut auth profile list
capcut auth profile show default
capcut auth profile set default --region KR --language ko-KR
```

## API status

Display the SDK operation inventory:

```bash
capcut api status
```

## Effects and materials

CapCut uses internal panel identifiers. The most important one is `effects2`,
which means the editing-effects panel (video effects such as Popular, Basic,
and Freeze Frame). Other identifiers are `transitions` (transitions), `filter`
(filters), `face-prop` (body/face effects), `subtitle-templates` (caption
templates), and `default` (general materials). Panel metadata returns the
human-readable category names and IDs.

Search effects:

```bash
capcut effects search QUERY [--offset N] [--count N]
capcut effects search blur
capcut effects search blur --offset 50 --count 50
```

Get suggested search terms:

```bash
capcut effects words
```

Inspect a material panel:

```bash
capcut panels info [--panel NAME]
capcut panels info --panel effects2
```

Use the category IDs returned by this command with the SDK's
`client.effects.list(category_id=..., category=..., panel="effects2")` method
to retrieve a specific category.

## Music

List music collections:

```bash
capcut music collections
```

List songs in a collection:

```bash
capcut music songs COLLECTION_ID [--offset N]
capcut music songs 123456 --offset 0
```

## Templates

List template collections:

```bash
capcut templates collections
```

List templates with a cursor:

```bash
capcut templates list COLLECTION_ID [--cursor VALUE]
capcut templates list 123456 --cursor 0
```

## AIGC helpers

Request random prompts for one or more model names:

```bash
capcut aigc prompts MODEL [MODEL ...] [--scene NAME]
capcut aigc prompts artistic_text
capcut aigc prompts artistic_text portrait --scene default
```

## Configuration

Get effect configuration:

```bash
capcut config effect-general [--scene NAME]
capcut config effect-general --scene default
```

Get remote application settings:

```bash
capcut config remote-settings
```

## Raw OpenAPI calls

Use `capcut call` for any documented operation that does not yet have a typed
resource command:

```bash
capcut call PATH REQUEST_JSON
capcut call --method GET PATH
capcut call --method POST PATH REQUEST_JSON
```

Examples:

```bash
capcut call /artist/v1/effect/search request.json
capcut call --method GET /model/api/arithmetics
capcut call --method POST /artist/v1/effect/general_config request.json
```

`REQUEST_JSON` is a local JSON file. The CLI signs requests through the
built-in `CapCutSigner` and uses the active profile's device and locale
settings.

## Common behavior

- Catalog requests use the default profile automatically.
- `has_more` responses expose `next_offset` or `next_cursor` for pagination.
- Login-required operations may return an authentication error with generated
  identifiers.
- Do not put real device identifiers, cookies, or response dumps in source
  control.

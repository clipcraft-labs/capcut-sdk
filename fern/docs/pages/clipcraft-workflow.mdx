# Clipcraft project workflow

The API SDK is the live catalogue provider in a larger, vendor-neutral video
build pipeline:

```text
CapCut API catalogue
  -> stable CatalogResource records
  -> clipcraft.lock
  -> SHA-256 local asset store
  -> Clipcraft Project compiler
  -> validated CapCut Desktop draft
```

Use the unified CLI when the end goal is a reproducible video project:

```bash
python -m pip install \
  "capcut-api-sdk @ git+https://github.com/clipcraft-labs/capcut-sdk.git" \
  "clipcraft-capcut-draft @ git+https://github.com/clipcraft-labs/capcut-draft.git" \
  "clipcraft-cli @ git+https://github.com/clipcraft-labs/clipcraft-cli.git"

clipcraft catalog effects search blur
clipcraft catalog panels categories --panel transitions
clipcraft catalog resources list \
  --panel transitions \
  --category-id CATEGORY_ID
clipcraft resolve effect blur --as hero-blur
clipcraft resolve resource \
  --panel transitions \
  --category-id CATEGORY_ID \
  --as intro-transition
clipcraft project build project.json \
  --lock clipcraft.lock \
  --out build/demo
clipcraft project validate build/demo
```

The verified compiler target is CapCut Desktop 9.1.0 on macOS. Draft layouts
are version-specific, so other targets are rejected unless you explicitly pass
`--allow-unsupported-version` and manually review the generated files against
that Desktop release.

Music resolution downloads a preview to a content-addressed local store and
records only its SHA-256 hash and size in the lock file:

```bash
clipcraft resolve music COLLECTION_ID \
  --pick 1 \
  --as background-music
```

Generated drafts are build artifacts. The portable `project.json` and reviewed
`clipcraft.lock` remain the source of truth. Do not commit downloaded media,
signed URLs, raw API responses, device identifiers, cookies, or Desktop index
files.

The same resource command supports known panels including `effects2`,
`transitions`, `filter`, `face-prop`, `subtitle-templates`, and `default`.
Stable catalogue records infer a corresponding kind such as `transition`,
`filter`, or `caption-template` while preserving the selected panel and
category in the lock.

Desktop registration is intentionally plan-first:

```bash
clipcraft project register build/demo --drafts-dir /path/to/Desktop/drafts
clipcraft project register build/demo --drafts-dir /path/to/Desktop/drafts --apply
clipcraft project open build/demo
```

The apply form writes only inside the selected drafts directory and preserves
existing metadata with `.bak` files.

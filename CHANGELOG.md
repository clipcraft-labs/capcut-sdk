# Changelog

## 0.2.0 - 2026-08-02

- Added exact resource-ID kind detection for effects, filters, transitions,
  caption templates, body effects, stickers, animations, audio effects, fonts,
  text effects, masks, catalogue images, and stock video.
- Added read-only resolution from the installed Desktop Resource SDK HTTP cache.
- Added exact music-ID resolution through a verified collection-scan fallback.
- Added normalized bundle URLs, hashes, metadata, and provider semantics for
  reproducible packaging.
- Published end-to-end Clipcraft, headless-render, and privacy documentation.

## 0.1.0

- Added stable catalogue records and structured CLI output for draft compilers, MCP servers, and Skills.
- Added CLI support for sound-effect music collections and local song preview downloads with automatic audio extensions.
- Added installable `src/capcut_sdk` package and `capcut` CLI entry point.
- Added the built-in CapCut signer and capture-backed effects, panel, and search clients.
- Added OpenAPI operation inventory converter.
- Added public-repository security policy and CI checks.

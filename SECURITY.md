# Security policy

This is an unofficial, reverse-engineered SDK. Do not report or commit real
device identifiers, cookies, access tokens, request signatures, or private
captures in issues and pull requests.

Use dummy identifiers in tests. If sensitive data is accidentally published,
remove it from the working tree and rotate/revoke it immediately; deleting a
file does not remove it from Git history.

The project does not provide a service account or shared credentials.
